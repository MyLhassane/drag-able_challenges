# Drag-able Challenges

A static web viewer for visualizing challenge relations from JSON data.

## Overview

This project renders a draggable network graph of challenges, categories, and players using plain HTML, CSS, and JavaScript.

## Files

- `index.html` – main application page
- `relation-network.css` – styling for the viewer
- `relation-network.js` – main JavaScript logic for rendering and interaction
- `rtdb-20.json` / `rtdb-20-light.json` – example JSON datasets
- `snap-v/` – saved position files and snapshots

## Usage

1. Open `index.html` in a browser.
2. Click the `📂 تحميل JSON` button to load a JSON dataset.
3. Drag nodes, save positions, and switch between challenges.

## Notes

- The UI is right-to-left and includes Arabic labels.
- Saved positions can be loaded from JSON files via the `Load Pos` button.
